# Changelog

## 0.1.0

- Preserves the blobatar `2.4.0` generation-2 seed-to-look mapping; existing
  names resolve to the same traits, palettes, silhouettes, and expressions as
  the pinned TypeScript reference vectors.
- Adds a Flutter-independent Dart core for normalization, hashing, traits,
  OKLCh colors, geometry, expressions, and deterministic elapsed-time motion.
- Adds static and animated Flutter painters and widgets with hover/always
  motion, expression morphing, reduced-motion support, and lifecycle-safe
  tickers.
- Adds the Blobatar Studio example, parity fixtures, and package CI checks.
